# CAREBASE

공개 사이트: https://carebaseone.com

한국어 https://carebaseone.com/ko · English https://carebaseone.com/en · 中文 https://carebaseone.com/zh

GitHub `hanbaedal/carebaseone`를 Render 웹 서비스가 빌드하고, 문의는 MongoDB Atlas `carebaseone.inquiries`에 저장합니다.

Render 환경 변수 `MONGODB_URI`에 Atlas 연결 문자열을 넣습니다. 예시는 `.env.example`을 참고합니다.
